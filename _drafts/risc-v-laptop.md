I posted recently about what [my dream laptop][dream-laptop] would look like, but that list of criteria was based on the fact that so much of the broader software ecosystem relies on Intel's x86 instruction set and the processors that use it. In a perfect world, we wouldn't be using proprietary instruction sets and closed-source hardware designs that do things like leave a theoretical backdoor open in every single processor that they produce. In a perfect world, we would use a chipset whose instruction set is entirely open source such that anyone can inspect how it works and what it's doing. And that's exactly what the [RISC V][risc-v] architecture does, however it is at the moment nowhere near widely adopted. So from a practicality standpoint, it's not a great pick for the average computer user. But for hobbyists, tech enthusiasts, and the paranoid, diving in might be a worthwhile proposition, if only to demonstrate demand for an open replacement to x86.
