If you just want to quickly download the dotfiles and scripts that I use, run the following in your terminal:

```
$ wget https://github.com/paranoid-porygon/arch-config/archive/refs/heads/main.zip
```

You will need to have a way to extract the zip file contents, and I find unzip to be the easiest.

```
$ sudo pacman -S unzip
$ unzip main.zip
```
